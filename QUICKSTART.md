# 🚀 Quick Start Guide

## Get Started in 3 Steps

### Step 1: Generate Your Marketing Strategy
```bash
python3 run_strategist.py "Your Course Title"
```

**Example:**
```bash
python3 run_strategist.py "Kubernetes for Production"
```

### Step 2: Review the Output
A JSON file will be created: `marketing_strategy_kubernetes_for_production.json`

This contains everything you need:
- ✅ Landing page content
- ✅ Ad scripts (Telugu + English)
- ✅ Email sequences
- ✅ Pricing strategies
- ✅ 30-day growth plan
- ✅ Content calendar
- ✅ And much more!

### Step 3: Implement Immediate Actions

Focus on these 3 quick wins first:

#### 1. Landing Page Urgency (30 minutes)

## Common Questions

**Q: Can I customize the generated content?**
A: Yes! The generated JSON is a starting point. Edit it to match your brand voice and specific course details.

**Q: How often should I run the strategist?**
A: Run it once per course. If you add new courses or update existing ones, generate fresh strategies.

**Q: What if I don't have video testimonials yet?**
A: Start with text testimonials. Record videos as students complete the course and gradually replace text with video.

**Q: Which platform should I focus on first?**
A: Start with 2-3 platforms you're comfortable with. We recommend:
1. Instagram (visual, engaging)
2. Email (direct, converts well)
3. YouTube (authority, SEO)

**Q: How much budget do I need?**
A: Minimum ₹10,000/month for paid ads. You can start with organic content (free) and add paid advertising as you see results.
